How to Run this File:

  -First you must open the terminal to navigate to the folder with the .pmg and C code
  -Then open type in the terminal gcc <name_of_file>.c -o Part1
  -Then type ./Part1
  -Double click the a.out file to create the image output in the folder
  -To chnage the photo used, change the name in the fopen, and fclose line
